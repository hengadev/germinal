# 013 — Open Graph / Twitter Card metadata

**Type:** AFK
**Status:** open
**Blocked by:** None

## What to build

Add Open Graph and Twitter Card meta tags to Event, Talent, and Ticket pages, so links shared on social platforms and messaging apps show a proper title, description, and image preview instead of a bare URL.

## Acceptance criteria

- [ ] Sharing an Event, Talent, or Ticket page link produces a rich preview (title, description, image) when validated against a social-preview debugging tool.
- [ ] Each page type's preview uses content relevant to that specific Event/Talent/Ticket (not a single generic site-wide preview).
